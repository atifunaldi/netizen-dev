# Netizen iOS / tvOS apps

Three independent applications, one shared identity: Powered by Netizen Global Agency.

- CarPlayPrototype: Netizen Drive, existing iPhone app, v1.1 preparation.
- NetizenApps/News: Netizen News reader for iPhone, two editorial sources.
- NetizenApps/TV: Netizen Signage, tvOS full-screen digital signage application (not a system screensaver).

All projects use the same icon generated by CarPlayPrototype/generate-app-icon.swift with an optional output argument. Their bundle identifiers are placeholders until Apple Developer identifiers, profiles and App Store Connect records are created.

To generate projects on a Mac runner: run icon generator for each project, then `cd NetizenApps/News && xcodegen generate` and similarly for TV. No signing or upload workflow is enabled for the new apps yet.

The news app uses public WordPress REST endpoints and will show an error if the sites disable the REST API. Verify the editorial feed and image licenses before distribution.

## Push notifications (Netizen News)
The app now has per-publication switches, an explicit iOS notification permission prompt, APNs token registration handling, and allowlisted article links opened from notification taps. **Push delivery is not live.** Required production work:
1. Register the Netizen News App ID in Apple Developer and enable Push Notifications; create an APNs-enabled provisioning profile and appropriate entitlements.
2. Deploy an authenticated HTTPS backend to accept APNs device tokens and source subscriptions, supporting unsubscribe, deduplication, and token deletion.
3. Add WordPress publish-event webhooks on both owned sites. Authenticate webhook messages; send only newly published posts, not drafts or updates.
4. Backend uses an APNs signing key stored as a server secret, never in this public GitHub repository.
5. Verify actual device delivery, background behavior, and notification tap handling in TestFlight.

The in-app switches currently store preferences locally; backend synchronization is not yet connected. No APNs keys or signing credentials have been added.
